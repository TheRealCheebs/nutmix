# Contributing Guide

## How to Contribute
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests and lint
5. Submit a pull request

- Follow Go best practices (Go >= 1.23 recommended, Go 1.25 or newer preferred)
- Write clear commit messages
- Add tests for new features

## CI/CD
GitHub Actions will run tests and lint checks on each pull request.
